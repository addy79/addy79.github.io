Digitwin1

Hardware-in-the-Loop 1-DOF Robotic Actuator Digital Twin

An end-to-end cyber-physical digital twin connecting a 1-DOF robotic actuator with an OpenXR spatial simulation in Godot 4. Features a standalone Python daemon running on a Raspberry Pi Zero, streaming encoder angles, commanded setpoints, and torque feedback over low-latency UDP sockets. Includes dynamic joint limits, real-time telemetry gauges, and automated safety interlocks.
