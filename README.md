# Asmae El Harti — Engineering & Academic Portfolio

Portfolio website of **Asmae El Harti** ([addy79](https://github.com/addy79)), hosted at **[addy79.github.io](https://addy79.github.io/)**.

Built with an **al-folio** aesthetic: clean whitespace typography, dark/light theme switching, responsive floating profile cards, interactive project filtering, academic citations, and client-side instant search (`Ctrl+K`).

---

## 🚀 Key Sections

* **About (`/`)**: Engineering philosophy, Technical Skills (*The Body: Mechatronics & Hardware* vs *The Brains: Autonomy & Simulation*), news milestones, and featured projects.
* **Projects (`/projects/`)**: Filterable project gallery covering:
  * **Digitwin1**: Hardware-in-the-Loop 1-DOF robotic actuator digital twin (Godot 4 + OpenXR + Raspberry Pi Zero over UDP).
  * **FreeCAD Mechanical Suite**: 44 fully parametric mechanisms (cycloidal drives, harmonic reducers, planetary gearboxes, Stewart platform, Delta robot, Tourbillon, Jet Engine).
  * **VRMechanics & BrushlessLab**: Spatial computing laboratories for disassembly & BLDC motor diagnostic testing.
  * **Pioneer ROV**: Marine robotics exploration submersible with AUI Robotics Club.
  * **Racer3D**: Physics engine with raycast suspension & vehicle dynamics.
* **Publications (`/publications/`)**: Academic research proposals, whitepapers, and engineering reports with 1-click BibTeX citation copying and abstract accordions.
* **Curriculum Vitae (`/cv/`)**: Structured academic CV with print-to-PDF support.

---

## 🛠️ Tech Stack

* **Styling**: Bootstrap 4.6, FontAwesome 6, Academicons, Google Fonts (Roboto, Roboto Slab, JetBrains Mono).
* **Theming**: CSS Custom Properties with light/dark/system detection & `localStorage` persistence.
* **Deployment**: GitHub Pages (`.nojekyll` static deploy).
